# Rent360 image credits

Every photograph in the Rent360 concept gallery is released under **Creative Commons Zero
(CC0 1.0 Universal)** — dedicated to the public domain, cleared for commercial use, and free of
any attribution requirement. Credits are listed anyway so the provenance of each file is
verifiable without leaving this repository.

Sourced through [Openverse](https://openverse.org), which reports the licence for each work.
Files were centre-cropped to 3:2 and resized to 900 × 600 for the gallery; source EXIF was not
carried over. No other modifications were made.

## Why this file exists

The gallery previously used interior photographs with no recorded source or licence. They were
replaced on 2026-08-30 with the CC0 set above so the concept can be shown publicly, in a
portfolio, or to a client without any licensing question attached to it.

The photographs depict real interiors and are **not** the properties of a real Rent360 customer —
Rent360 is an unofficial design concept, and every listing, price, guest name and metric in the
page is invented sample data.
